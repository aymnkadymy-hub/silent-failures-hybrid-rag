# Data Availability

Statement for the manuscript:

> Qur'an QA 2023 and the BEIR collections SciFact, NFCorpus and ArguAna are public (Section 3.2). The code of the fault-injection study and of the controller, the fault implementations, the constants fixed before the confirmatory runs, the registered hypotheses, the analysis scripts and the stored results behind every table and figure are in the GitHub repository https://github.com/aymnkadymy-hub/silent-failures-hybrid-rag, which is private and is shared with the editors and reviewers on request to the corresponding author. The frozen Arabic retrieval package (T1) is derived from a deployed service and from printed editions under copyright; it is available from the corresponding author on reasonable request, and the repository lists the SHA-256 hash of each of its files.
